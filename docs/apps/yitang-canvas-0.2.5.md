# 一堂画布 0.2.5

作者：尹白猿。应用 ID：`com.yinbaiyuan.yitang-canvas`。

## 功能与入口

提供五步法·基础取舍版和一堂双三角两套空白画布。五步法保留六列九个填写区域；双三角保持上排场景、审美、体系，下排数据、基本功、创造力，金黄和天蓝分别标识人类三角与 AI 三角。

支持逐条多行文字与数字、Shift+Enter 新增下一条、拖动和键盘排序、删除撤销、自动保存、复制、搜索、归档恢复、可选项目关联、Markdown 与 JSON 导出。条目不增加状态、负责人、期限或计算表。无 AI 调用、后台定时任务、桌面卡片或跨实例同步；JSON 目前提供备份导出，没有导入界面。

主窗口使用 React，Node 后端按需启动。工作台中的应用商店刷新公共源后可找到「一堂画布」。

## 兼容、能力与数据

- SDK API / 构建工具包：1.1.0；最低 Core：0.5.3；Node.js 24。
- `filesystem` 用于通过公共 workspace 接口读取可选项目，以及 SDK 受管 JSON 保存。后端以当前用户身份运行，声明不是沙箱隔离。
- 业务数据为 `canvases.json`，user scope、schemaVersion=1；没有数据迁移。新安装从空白库开始，模板不带示例答案。
- 停止输入约 600ms 后保存，支持 Cmd/Ctrl+S。关闭保护等待保存；失败和版本冲突保留浏览器草稿，旧版本写入不能覆盖新版本。
- 单条最多 5 万字，单份约 700KB，最多 1000 份画布。项目不可访问时仍可独立编辑。
- 既有手动导入安装不会自动改为公共源安装。本次发布不卸载既有应用、不修改其来源或数据。
